# da474e6 — feat: 서재 검색 진입 아이콘 보강

**Files**: `LibraryScreen.kt`, `LibraryScreenTest.kt`, `strings.xml`

## 결정

- 탭 아래에 검색 진입용 `+` 버튼을 항상 노출하고, 빈 서재의 검색 버튼과 동일한 `onSearch` 액션을 사용한다.

## 이유

- 책이 있는 서재에서도 빈 서재와 동일하게 새 책을 검색·추가하는 행동을 시작할 수 있어야 한다.
- 화면 상태마다 별도 동작을 만들지 않고 기존 검색 콜백을 재사용해 검색 진입 의미를 일관되게 유지한다.
- 단독 아이콘인 `+` 버튼에는 접근성 설명을 제공하고, 텍스트가 함께 있는 아이콘은 장식으로 처리해 중복 음성 안내를 막는다.
