# 2a89a8f — feat: 검색 진입과 최근 검색어 화면 구현

**Files**: `SearchViewModel.kt`, `SearchScreen.kt`, `SearchNavigation.kt`

## 결정
- 최근 검색어 조회 상태를 불변 `SearchUiState`로 노출하고 재시도 시 저장소 Flow를 새로 구독한다.
- 검색 제출 전 화면은 입력 상태를 UI에 두고 최근 검색어 표시만 담당한다.

## 이유
- lifecycle-aware 수집과 단방향 상태 흐름을 유지하면서 로딩·빈 목록·오류·재방출을 한 계약으로 표현하기 위해서다.
- 디바운스, 로컬 필터, Paging 결과는 후속 PR 범위이므로 현재 입력이 저장소 검색 계약을 실행하지 않게 분리했다.
