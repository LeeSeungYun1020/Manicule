# fa14a44 — feat: 책 정보 조회와 상세 기본 화면 구현

**Files**: `BookRepositoryImpl.kt`, `NlkContentFetcher.kt`, `BookDetailViewModel.kt`

## 결정
- 소개·목차는 inline 값을 우선하고, 비어 있을 때만 허용된 NLK HTTPS URL을 병렬 조회한다.
- 상세 화면은 캐시를 먼저 표시하며 최초 탭 선택만 서재 등록 여부로 결정한다.

## 이유
- 보조 콘텐츠 조회 실패가 기본 서지정보 캐시를 무효화하지 않도록 부분 실패를 허용했다.
- 사용자 탭 선택과 프로세스 복원 상태를 이후 서재 데이터 방출보다 우선해 화면 이동을 방지했다.
