# 7f16326 — 스캔 권한과 CameraX Preview 구현

**Files**: `ScannerViewModel.kt`, `CameraPreview.kt`, `ScannerScreen.kt`

## 결정

- `BarcodeReader`는 권한 승인 뒤 ViewModel이 생성하고 화면 재생성 동안 재사용하며, ViewModel 종료 시 닫는다.
- Preview와 ImageAnalysis는 화면 lifecycle에 함께 바인딩하고 해당 화면이 소유한 UseCase만 해제한다.
- 회전은 물리 각도가 아니라 현재 `display.rotation`을 사용하며 `DisplayListener`로 두 UseCase를 갱신한다.
- 21:13 가이드는 프로토타입 UI 비율로만 사용하고 분석 영역을 자르거나 결과를 제한하지 않는다.
- 영구 거부 판단은 권한 요청 결과와 rationale을 함께 사용하고, 설정 실행 실패에도 검색 대안을 유지한다.

## 이유

- 분석기 수명과 카메라 lifecycle을 분리해야 Activity 재생성에서 분석기를 중복 생성하지 않고 안전하게 재바인딩할 수 있다.
- CameraX가 기대하는 표시 회전값을 직접 전달하면 0/90/180/270도 화면 변화에 대응하면서 불필요한 센서 각도 추적을 피할 수 있다.
- 가이드를 인식 조건으로 사용하면 책과 촬영 환경에 따라 바코드가 프레임 밖에 걸리는 경우를 놓칠 수 있다.
- 최초 요청 전에도 rationale은 false일 수 있으므로 그 값만으로 앱 설정으로 보내면 정상적인 최초 권한 요청을 건너뛴다.
