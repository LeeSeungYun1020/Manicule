# d804e5e — feat: 상단·탐색 공용 컴포넌트 추가

**Files**: `ManiculeSearchBar.kt`, `ManiculeTabRow.kt`, `ManiculeTopAppBar.kt`

## 결정
- 검색 결과는 feature 화면이 소유하고 공용 검색 바는 `TextFieldState` 기반 입력·제출·read-only 진입만 제공한다.
- 공용 탭은 항목 타입과 표시 문자열을 분리하고 선택 상태는 index로 받는다.
- 상단 앱바의 스크롤 상태와 action scope는 Material 3 계약을 그대로 노출한다.

## 이유
- 검색 결과와 내비게이션을 공용 컴포넌트에 결합하지 않아 홈·검색 화면이 같은 입력 UI를 서로 다른 흐름으로 사용할 수 있다.
- typed 탭 항목을 지원하면서 Material 3 `SecondaryTabRow`의 index 계약을 유지한다.
- 화면이 `nestedScroll`을 연결하고 여러 action을 배치할 수 있어야 앱바 동작을 일관되게 조립할 수 있다.
