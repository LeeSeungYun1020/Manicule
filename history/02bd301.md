# 02bd301 — feat: 서재 정렬 계약 구현

**Files**: `LibrarySort.kt`, `BookEntryDao.kt`, `GetLibraryBooksUseCase.kt`

## 결정

- 서재 정렬을 기준과 방향을 묶은 `LibrarySort` 값 객체로 전달하고 기본값은 수정일 내림차순으로 둔다.
- Room에는 추가일·수정일·별점의 오름차순/내림차순 쿼리를 각각 명시하며 ISBN 보조 정렬은 두지 않는다.
- 별점이 같은 경우에만 최근 수정된 책을 먼저 보여 주도록 `updatedAt DESC`를 보조 기준으로 사용한다.

## 이유

- 명시적인 Room 쿼리는 여섯 정렬 조합을 컴파일 시점에 검증하고 정렬 의미를 데이터 경계에 고정한다.
- ISBN은 사용자가 인지하는 목록 순서가 아니므로 같은 날짜나 같은 별점·수정일의 순서까지 강제할 필요가 없다.
