# 8640459 — fix: 검색 Paging 요청 크기 일치

**Files**: `BookRepositoryImpl.kt`, `BookRepositoryImplTest.kt`

## 결정

- 검색 Pager의 최초 요청 크기를 네트워크 페이지 크기 10개와 일치시킨다.

## 이유

- 페이지 번호 기반 API에서 기본 `initialLoadSize = pageSize * 3`을 사용하면 후속 페이지 계산 시 항목 누락이나 중복이 발생할 수 있다.
- 이번 구현은 기존 요청 크기 10개를 유지하고, 초기 로드 크기 최적화는 페이지 계산을 수정하는 후속 이슈 #48에서 검토한다.
