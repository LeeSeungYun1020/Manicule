# 174724c — feat: 검색 결과 책 상세 이동 조립

**Files**: `ManiculeNavHost.kt`, `SearchNavigationTest.kt`, `NavigationRepositories.kt`

## 결정

- 검색 결과 ISBN을 기존 BookDetailRoute에 연결하고 책 상세의 기본 탭 정책은 유지한다.
- 검색의 스캔 상태는 production에서 Unavailable로 전달한다. 실제 이동은 V2 계약 준비 후 I1에서 연결한다.
- Hilt 테스트 Repository와 실제 앱 화면을 사용해 상세 이동, 상단·시스템 뒤로가기와 검색 상태 복원을 검증한다.

## 이유

- 사용자가 확정한 한 PR 범위에서 필수 콜백 변경과 최소 앱 조립을 함께 완성하기 위해 V1 구현 뒤 별도 앱 조립 커밋으로 연결했다. 변경 파일 수가 20개를 넘지만 독립 feature 테스트와 앱 Navigation 테스트가 같은 결과 선택 흐름을 검증하므로 한 PR 범위를 유지한다.
- fake Repository로 외부 API 없이 route 인자·백스택·목록 복원을 확인한다. 임시 NLK_AUTH_KEY는 빌드 구성에만 사용하고 실제 통신 검증으로 간주하지 않는다.
