# 59356f3 — feat: 리마인더 설정 화면 구현

**Files**: `SettingsRoute.kt`, `SettingsViewModel.kt`, `NotificationPermission.kt`

## 결정

- Android 13 이상에서 알림 권한이 없으면 권한 승인 전까지 리마인더를 활성화하지 않는다.
- 권한 거부 시 리마인더를 OFF로 유지하고, 스낵바에서 앱 알림 설정으로 이동하는 복구 경로를 제공한다.

## 이유

- 실제 알림을 보낼 수 없는 상태에서 설정과 Scheduler 상태가 활성화되는 불일치를 방지한다.
- 거부 직후 권한을 반복 요청하지 않으면서 사용자가 필요할 때 시스템 설정에서 직접 복구할 수 있게 한다.
