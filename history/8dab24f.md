# 8dab24f — feat: 책 상세 독서 상태 변경 구현

**Files**: `BookEntryDao.kt`, `ChangeReadingStatusUseCase.kt`, `BookDetailScreen.kt`

## 결정

- 미등록·UNSET은 미선택으로 표시하고, 상태를 탭할 때 서재에 등록한다. 기존 리뷰는 보존한다.
- ISBN 기반 상태 변경을 DAO 트랜잭션으로 처리하며, 기존 Entry는 상태·수정 시각·완독일만 갱신한다.
- FINISHED 진입 시 로컬 날짜를 저장하고 이탈 시 제거한다. 같은 상태 재선택은 날짜·시각을 유지한다.
- 한 번 읽은 Clock 시각으로 수정 시각과 완독일을 계산한다.
- 상태 선택 UI는 M3 단일 선택 세그먼트를 직접 사용한다.
- DB 관찰값을 선택 상태로 표시하고, 저장 중 입력 차단·실패 재시도를 ViewModel에서 관리한다.

## 이유

- 사용자 확정에 따라 화면을 열거나 리뷰만 작성한 것으로 독서 상태를 자동 지정하지 않는다. 프로토타입 5c의 WANT 선택 예시는 등록된 책에만 적용한다.
- Entry 전체 저장은 오래된 리뷰·서지정보를 덮어쓸 수 있다. 부분 갱신과 트랜잭션으로 동시 등록·상태 변경의 데이터 보존을 보장한다.
- 같은 상태 재선택이 서재 정렬이나 완독일을 바꾸지 않게 하고, 자정 경계에서도 날짜와 시각을 일치시킨다.
- 기존 공용 세그먼트에는 disabled 계약이 없다. feature에 M3 컴포넌트를 사용해 저장 중 비활성화를 지원하고 공용 UI 변경 범위를 늘리지 않는다.
- 낙관적 화면 갱신의 복원 경쟁을 피하고, 저장 오류가 새로고침 오류 뒤에 가려지지 않도록 저장 실패 스낵바를 우선한다.
