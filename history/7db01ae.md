# 7db01ae — docs: PR 작업 및 리뷰 절차 정리

**Files**: `plan/order.md`, `skills/work.md`, `skills/code-review.md`

## 결정

- PR은 하나의 리뷰 초점과 완료 가능한 하위 흐름으로 분할한다.
- PR 작업 계획은 `current.md`에 기록하지 않고, 작업 종료 시 담당 레인의 상태와 다음 범위만 갱신한다.
- 리뷰 반영은 같은 원인의 리뷰를 그룹화하되 개별 리뷰의 처리 결과를 유지한다.

## 이유

- PR 범위와 리뷰 부담을 줄이고 독립 범위의 병렬 구현을 허용한다.
- 병렬 PR이 공유 상태 문서에서 충돌하는 범위를 최소화한다.
- 중복 수정을 줄이면서 리뷰별 해결 여부를 추적할 수 있게 한다.
