# 9616340 — fix: 검색 Paging 고정 요청 크기 및 페이지 간 ISBN 중복 제거

**Files**: `NlkBookPagingSource.kt`, `BookRepositoryImpl.kt`

## 결정
- `NlkBookPagingSource`에 고정 요청 크기(`pageSize = 10`) 및 누적 ISBN 중복 필터링을 적용하고, `PagingConfig`의 `pageSize = 10`, `initialLoadSize = 10`을 유지한다.

## 이유
- **페이지 번호 API 정합성**: 국립중앙도서관 API는 `page_no` 기반이므로 요청 크기 가변 시 페이지 경계 중복·누락이 발생한다. PagingSource 내부에서 `pageSize`를 고정하여 외부 `loadSize` 변동과 무관하게 1:1 페이지 번호 조회를 보장한다.
- **다중 페이지 중복 방지**: 제목·저자 병렬 조회 및 페이지 간 동일 도서 반환 시 발생할 수 있는 Compose LazyColumn 키 충돌을 방지하기 위해 `seenIsbns` 세트로 누적 중복을 제거한다.
- **요청 크기 트레이드오프(10 vs 20+)**: 제목·저자 동시 요청으로 1회당 최대 20건이 반환되므로 모바일 초기 뷰포트를 채우기에 충분하며, 초기 응답 시간 및 불필요한 트래픽을 줄이기 위해 `pageSize = 10`, `initialLoadSize = 10`이 가장 적합하다.
