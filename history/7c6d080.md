# 7c6d080 — refactor: BookProgressBar에서 불필요하게 명시된 LinearProgressIndicator 기본 색상 설정 제거

**Files**: `core/ui/src/main/java/com/leeseungyun1020/manicule/core/ui/book/BookProgressBar.kt`

## 결정
- `LinearProgressIndicator` 호출 시 불필요하게 명시된 `color`, `trackColor` 인자 제거

## 이유
- Material 3 기본 컴포넌트는 내부적으로 알맞은 테마 색상(`primary`, `surfaceVariant`)을 기본으로 제공하므로 명시적으로 지정하지 않는 것이 코드를 간결하게 유지하는 데 유리함.
- 프로젝트 내 `core/ui` 하위 유사 케이스 조사 결과, `BookListItem` 레이아웃 구조 변경(`Surface` 도입) 등의 리팩토링 방안도 있었으나, 이번 작업 범위에서는 명백하게 불필요한 기본값만 제거하기로 결정.
