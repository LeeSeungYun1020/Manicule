# 3c3d385 — feat: 검색 결과 선택과 복귀 상태 보완

**Files**: `SearchScreen.kt`, `SearchScannerAction.kt`, `SearchResultList.kt`

## 결정

- 도서 행 전체에서 ISBN 선택 콜백을 전달하고 행 사이에 구분선을 표시한다.
- 제출 ID별로 목록 상태를 저장한다. 동일 검색어 재제출은 새 목록으로 시작하고 상세 복귀는 기존 위치를 복원한다.
- 스캔 버튼은 표시하되 `Unavailable`이면 비활성화한다. 연결 가능한 상태만 실제 콜백을 포함하며 navigation 기본 빈 람다는 제거한다.
- Paging append·재시도와 화면 복원은 실제 Pager 및 제어 가능한 fake로 검증한다. 정적 테스트·Preview 데이터에는 완료 LoadStates를 명시한다.

## 이유

- 검색어만으로 스크롤 초기화를 판단하면 동일 검색어 재제출과 화면 재진입을 구분할 수 없다.
- #49와 사용자 확정 범위에 따라 스캔 UI 제공과 I1 연결 시점을 분리하고, 미완성 이동을 활성 동작으로 노출하지 않는다.
- Paging 3.3.2의 정적 PagingData는 기본 생성 시 LoadStates를 전달하지 않아 Preview·UI 테스트가 초기 로딩에 남을 수 있다.
