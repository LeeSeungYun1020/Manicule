# daf4ab3 — feat: 서재 정렬 UI 구현

**Files**: `LibraryViewModel.kt`, `LibraryScreen.kt`, `SortBottomSheet.kt`

## 결정

- 적용된 정렬은 ViewModel이 소유하고, 정렬 시트에서 편집 중인 기준과 방향은 화면의 드래프트 상태로 분리한다.
- 책이 있는 상태에서만 정렬 진입과 현재 정렬 요약을 노출하고 적용 버튼을 눌렀을 때만 목록을 다시 구독한다.

## 이유

- 시트를 취소하거나 닫을 때 기존 목록 순서를 보존하고, 탭 전환과 재시도에서도 사용자가 적용한 정렬을 유지하기 위해서다.
- 빈 목록에는 정렬 결과가 없으므로 검색·스캔 행동에 집중하도록 불필요한 액션을 숨긴다.
