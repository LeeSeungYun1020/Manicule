# 48be36b — feat: 통계·도서 표시 컴포넌트 확정

**Files**: `ManiculeStatTile.kt`, `BookCover.kt`, `BookProgressBar.kt`

## 결정
- 통계 타일은 값·라벨을 하나의 접근성 항목으로 묶고 아이콘은 선택적 슬롯으로 받는다.
- 책 표지의 Small·Medium 치수는 `BookCover`가 `size` 인자로 직접 적용한다.
- 독서 진행률의 시각값과 백분율은 0~100%로 제한하고 페이지 표시는 입력값을 유지한다.

## 이유
- 홈과 통계가 서로 다른 아이콘을 사용해도 같은 수치 표시와 접근성 단위를 공유할 수 있어야 한다.
- 호출부마다 표지 너비와 높이를 함께 지정해 생기는 크기 계약 이탈을 막는다.
- 전체 페이지가 없거나 현재 페이지가 초과된 데이터에서도 유효한 진행 표시를 보장하면서 원본 페이지 정보는 확인할 수 있어야 한다.
