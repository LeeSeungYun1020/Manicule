# 7a2b1dd — feat: 검색 실행과 Paging 결과 구현

**Files**: `SearchViewModel.kt`, `SearchScreen.kt`, `SearchResultList.kt`

## 결정

- 최근 검색어는 입력 변경마다 즉시 필터링하고, 도서 검색은 IME 제출 또는 검색어 항목 선택 시에만 실행한다.
- 검색 화면을 입력 단계별 콘텐츠와 Paging 결과 상태 컴포넌트로 분리한다.
- 동일 검색어를 다시 제출해도 새 검색을 실행한다.

## 이유

- 최근 검색어는 최대 10개의 로컬 데이터이므로 디바운스가 제공하는 이점보다 즉각적인 반응이 중요하다.
- `WhileSubscribed(5_000)`은 화면 재생성 중 상태 구독을 유지하기 위한 설정이며 입력 디바운스와 무관하다.
- 검색 결과의 ISBN 중복 가능성은 저장소 Paging 경계를 수정하는 후속 이슈 #48에서 해결한다.
