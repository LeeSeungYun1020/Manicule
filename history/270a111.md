# 270a111 — feat: 서재 초기 탭 진입 계약 추가

**Files**: `LibraryNavigation.kt`, `LibraryViewModel.kt`, `TopLevelDestination.kt`

## 결정

- `LibraryRoute(initialTab = LibraryTab.READING)`을 기본 진입 계약으로 두고, 홈 '고르기'에는 `LibraryTab.WANT`를 사용한다.
- 서재에 표시할 세 상태만 `LibraryTab`으로 노출하고 도메인의 `UNSET`은 제외한다.
- 새 백스택 항목은 초기 탭을 사용하고, 복원 시에는 `SavedStateHandle`의 사용자 선택을 우선한다.
- V6는 5개 PR로 순차 진행하며, 이번에는 진입 계약만 구현한다. 홈 활성화와 콜백 조립은 PR 5에서 진행한다.

## 이유

- 홈이 서재 내부 상태를 직접 변경하지 않고 feature 소유 타입 안전 경로로 원하는 탭을 요청할 수 있어야 한다.
- 초기 인자를 재적용하면 탭 이동·테마 변경·프로세스 복원 후 사용자 선택이 초기화된다. 일반 하단 탭의 `restoreState` 동작을 유지하고, '고르기'는 새 항목으로 진입하도록 구분한다.
- Navigation의 enum 인자 복원은 클래스 이름을 사용하므로 `@Keep`으로 릴리스 난독화에서 보호한다.
- 계약을 먼저 검증·리뷰·머지하면 홈 상태 조합, 읽는 중 목록, 최근 7일 요약, 앱 조립을 각각 독립적으로 검토할 수 있다.
