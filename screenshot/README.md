# 실제 앱 화면 캡처

- 기기: Samsung Galaxy S23 Ultra (`SM-S918N`), 세로 `1080 × 2316`
- 앱: 읽음표 `0.1.0` 디버그 빌드
- 촬영: 2026-09-28 ~ 2026-09-29, 한국어, 기본 라이트 테마
- 방식: 앱의 실제 화면을 PNG로 저장. UI 합성·프로토타입 이미지 사용 없음.
- 데이터: 실제 도서 서지 정보·표지와 시연용 별점·메모·독서 기록. 상태별 촬영을 위해 도서 상태를 전환함.

## 시연 도서

| 도서 | ISBN | 전체 페이지 | 읽는 중 화면의 진도 |
|---|---|---:|---:|
| Kotlin in action 2/e | 9791161759692 | 803 | 157쪽 · 20% |
| 시작의 기술 | 9788901230658 | 227 | 150쪽 · 66% |
| 돈의 심리학 | 9791191056372 | 393 | 374쪽 · 95% |
| 더 시스템 | 9791188102259 | 381 | 완독 상태 예시 |

표지·페이지는 앱에 저장된 국립중앙도서관 서지 정보를 사용했다. 독서 기록 412건은 시연 데이터이며 실제 사용자의 독서 이력이 아니다.

## 홈 표시 조건

| 캡처 | 서재·기록 조건 | 표시 |
|---|---|---|
| [첫 사용자](home-onboarding.png) | 서재 없음 + 독서 기록 없음 | 시작 안내·빈 달력 |
| [대기 도서만 있음](home-want-no-records.png) | 읽고 싶음 4권 + 독서 기록 없음 | 0쪽 요약·고르기 버튼 |
| [읽는 중·기록 없음](home-reading-no-records.png) | 읽는 중 4권 + 독서 기록 없음 | 0쪽 요약·책 목록 |
| [기록·읽는 중 있음](home.png) | 읽는 중 3권 + 기록 있음 | 연속 13일·오늘 42쪽·진도 |
| [읽는 중 없음·대기 있음](home-no-reading-want.png) | 기록 있음 + 읽는 중 0권 + 읽고 싶음 1권 | 독서 요약 유지·고르기 버튼 |
| [읽는 중 없음·대기 없음](home-no-reading-no-want.png) | 기록 있음 + 읽는 중 0권 + 읽고 싶음 0권 | 독서 요약 유지·검색/스캔 버튼 |
| [오늘 기록 없음](home-no-today.png) | 어제까지 연속 기록 + 오늘 기록 없음 | 연속 12일 유지·오늘 0쪽 |

홈의 연속 기록은 오늘 또는 어제까지 이어진 기록이다. 통계의 연속 기록은 **선택 기간 안의 최장 연속 기록**이므로 오늘 탭에서는 0일 또는 1일로 표시된다.

## 통계

| 캡처 | 표시 조건 |
|---|---|
| [전체 기록 없음](stats-empty.png) | 빈 달력·0일·0쪽·0권·오늘 목록 없음 |
| [오늘 독서 기록 있음](stats-today.png) | 9월 29일: 3권·42쪽, 오늘 읽은 책 목록 |
| [4주](stats-period.png) | 13일·1,474쪽·4권, 0 / 1–19 / 20–49 / 50–99 / 100+쪽의 달력 색상 |
| [날짜별 기록](stats-day.png) | 기록이 있는 9월 29일 달력 셀 선택, 책별 쪽수·횟수 |
| [주별 차트](stats-chart.png) | 4주 기간·주별 집계, 책 막대 + 페이지 꺾은선 |
| [일별 차트](stats-chart-daily.png) | 4주 기간·일별 집계, 최근 날짜로 가로 스크롤된 상태 |
| [1년](stats-year.png) | 약 1년 범위의 기록, 가로 스크롤 달력 |
| [월별 차트](stats-chart-monthly.png) | 1년 기간·월별 집계 |
| [기간 설정](stats-range.png) | 직접 선택 탭의 시작일·종료일 설정 |
| [직접 선택](stats-custom.png) | 선택 기간 적용 후 달력·요약·차트 |

책 권수는 완독 수가 아니라 해당 기간 기록에 나타나는 고유 ISBN 수다. 그래프는 구간별로 중복을 제거하므로 막대 권수의 합과 기간 요약 권수는 다를 수 있다.
