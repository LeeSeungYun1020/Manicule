# Manicule — 진행 현황

> 요청받은 레인의 현황과 `다음 범위`를 확인한다. `다음 범위`는 계획 후보이며 작업 착수 지시가 아니다.

## 완료된 기반

- C1 독서 기록·공유 쿼리, C2 feature 모듈·Navigation 경계, C3 공용 UI 계약을 완료했다.

## 실행 레인

| 레인 | 현황 | 다음 범위 |
|---|---|---|
| V1 검색 | 검색·Paging·상세 이동·ISBN 검색 완료·최근 검색어 삭제 | V2 완료 후 스캔 이동 조립 |
| V2 스캔 | 권한·CameraX Preview·회전·바코드 인식 → ISBN 조회 → 책 상세 이동 완료 | 실기기 검증(성공/실패·오프라인 캐시·회전·백그라운드·권한 변경) |
| V3 설정 | 리마인더 설정 완료 | 테마·라이선스·버전 |
| V4 책 상세 | 정보·상태 변경·독서 기록 목록·기록 추가·다 읽음 확인 완료 | 별점 인라인 저장 |
| V5 서재 | 상태별 목록·정렬·이동과 책 표지 상태 표시 완료 | 롱프레스 상태 변경·삭제·Undo |
| V6 홈 | 로컬 데이터 상태 조합·온보딩·읽는 중·요약 UI와 검색·상세·서재 이동 완료 | V2 완료 후 스캔 이동, V7 화면 완료 후 통계 이동 활성화 및 실기기 검증 |
| V7 통계 | 공유 집계와 달력 선택 완료 | 통계 달력·날짜별 기록·차트 조립과 스크롤 검증 |

## 앱 조립

| 레인 | 현황 | 다음 범위 |
|---|---|---|
| I1 | 검색·책 상세·서재·스캔 destination과 검색 결과 → 책 상세, 스캔 대체 → 검색, 스캔 성공 → 책 상세, 검색 결과 없음 → 스캔 이동 연결 완료 | 준비된 레인에 맞춰 나머지 이동·루트 테마를 조립 |
