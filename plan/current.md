# Manicule — 진행 현황

> 새 세션은 가능한 레인의 `다음 범위`부터 진행.

## 완료된 기반

- C1 독서 기록·공유 쿼리, C2 feature 모듈·Navigation 경계, C3 공용 UI 계약을 완료했다.

## 실행 레인

| 레인 | 현황 | 다음 범위 |
|---|---|---|
| V1 검색 | 검색·Paging·상세 이동·ISBN 검색 완료·최근 검색어 삭제 | V2 완료 후 스캔 이동 조립 |
| V2 스캔 | 권한·CameraX Preview·회전 처리 완료 | 바코드 인식 → ISBN 조회 → 책 상세 이동, 실기기 검증 |
| V3 설정 | 리마인더 설정 완료 | 테마·라이선스·버전 |
| V4 책 상세 | 정보·상태 변경·독서 기록 목록·기록 추가 완료 | 완독 확인; 별점·메모 저장 |
| V5 서재 | 상태별 목록·정렬·이동과 책 표지 상태 표시 완료 | 롱프레스 상태 변경·삭제·Undo |
| V6 홈 | 로컬 데이터 상태 조합·온보딩·읽는 중·요약 UI와 검색·상세·서재 이동 완료. 요약 오류 재시도는 요약만 다시 조회 | V2 완료 후 스캔 이동, V7 화면 완료 후 통계 이동 활성화 및 실기기 검증 |
| V7 통계 | 공유 집계와 달력 선택 완료 | 통계 달력·날짜별 기록·차트 조립과 스크롤 검증 |

## 앱 조립

| 레인 | 현황 | 다음 범위 |
|---|---|---|
| I1 | 검색·책 상세·서재·스캔 destination과 검색 결과 → 책 상세, 스캔 대체 → 검색 이동 연결 완료 | V2의 바코드 인식·조회·책 상세 이동 완료 뒤 검색 → 스캔을 활성화하고, 준비된 레인에 맞춰 나머지 이동·루트 테마를 조립 |
