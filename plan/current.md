# Manicule — 진행 현황

> 요청받은 레인의 현황과 `다음 범위`를 확인한다. `다음 범위`는 계획 후보이며 작업 착수 지시가 아니다.

## 완료된 기반

- C1 독서 기록·공유 쿼리, C2 feature 모듈·Navigation 경계, C3 공용 UI 계약을 완료했다.

## 실행 레인

| 레인 | 현황 | 다음 범위 |
|---|---|---|
| V1 검색 | 검색·Paging·상세·스캔 이동·ISBN 검색·최근 검색어 삭제 완료 | 없음 |
| V2 스캔 | 권한·CameraX Preview·회전·바코드 인식 → ISBN 조회 → 책 상세 또는 검색 이동 완료 | 없음 |
| V3 설정 | 리마인더 설정·테마 선택·라이선스·버전 완료 | 없음 |
| V4 책 상세 | 정보·상태 변경·독서 기록 목록·기록 추가·수정·삭제와 Undo·다 읽음 확인·별점 및 메모 인라인 저장 완료 | 없음 |
| V5 서재 | 상태별 목록·정렬·이동·책 표지 상태 표시와 롱프레스 상태 변경·삭제·Undo 완료 | 없음 |

| V7 통계 | 공유 집계·달력 선택·기간 전환(오늘/4주/1년/직접 선택) 달력과 요약·기간 설정 시트·날짜별 기록 시트·오늘 읽은 책 목록·일/주/월 복합 차트 완료 | 없음 |
