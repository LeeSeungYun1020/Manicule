# 읽음표

국어: 읽음표 - 나의 독서 기록
영어: Manicule — A Reader's Mark

## 1. 컨셉

읽은 책, 읽고 있는 책, 읽고 싶은 책을 한 곳에서 관리하는 개인 서재 앱.
국립중앙도서관 API로 국내 도서 서지 정보를 검색하고, 독서 상태와 메모를 기록한다.

---

## 2. 타겟 사용자

- 읽은 책을 기록해두고 싶은데 마땅한 앱이 없는 독서 애호가
- 독서 목표를 세우고 달성 여부를 확인하고 싶은 사람
- 서점에서 책을 발견했을 때 나중에 읽으려고 메모해두는 사람

---

## 3. 핵심 기능

### 3.1 홈

- 검색창 — 탭 시 검색 화면으로 이동 (키보드 자동 포커스)
- 바코드 스캔 버튼 — 탭 시 바코드 스캔 화면으로 이동
- 읽는 중인 책 목록 (섹션 헤더 우측 "더보기" 버튼 탭 시 서재 탭으로 이동)
    - 읽는 중인 책이 없을 때: "아직 추가한 책이 없어요" 제목, "책을 검색하거나 스캔해 기록을 시작해 보세요" 메시지. 검색 버튼 및 스캔 버튼.
- 독서 요약 카드: 독서 달력 미리보기 (최근 7일), 연속 기록 일수, 오늘 읽은 페이지 수 — 탭 시 통계 화면으로 이동

### 3.2 책 검색

- 제목, 저자, ISBN으로 국내 도서 검색
- 검색 결과: 총 검색 결과 건수 표시, 컴팩트 리스트 형태(표지 이미지, 제목, 저자, 출판사, 발행일)
- 최근 검색어: 검색어 히스토리 제공, 탭 시 해당 검색어로 재검색
    - 검색어 저장 켜기/끄기 토글 제공
    - 검색어 개별 삭제 가능 (삭제 즉시 실행되지 않고 스낵바 노출, '실행취소' 탭 시 복구)
- 검색 결과 없는 경우: "검색 결과가 없어요" 제목, "책에 있는 바코드를 스캔해 찾아보세요" 메시지. 스캔 버튼.
- ISBN 바코드 스캔으로 즉시 검색 (카메라 권한 필요)
    - 카메라 권한 거부 시 "카메라 접근 권한이 필요해요" 제목, "바코드를 스캔하기 위해 카메라 권한을 허용해 주세요" 메시지. "카메라 사용" 버튼, "검색" 버튼.
    - 스캔 실패 시 "바코드를 인식하지 못했어요" 제목, "제목이나 저자로 검색해 찾아보세요" 메시지. 검색 버튼.

### 3.3 책 상세

- 책 정보 - 표지, 정보(재목, 저자, 출판사, 발행일, 페이지, 가격), 소개, 목차
- 내 기록 - 독서 상태 설정, 내 리뷰, 독서 기록
- 상태: 읽고 싶음 / 읽는 중 / 다 읽음 설정
- 내 리뷰: 별점(1~5 정수) 및 메모 기록
- 독서 기록: 날짜별로 읽은 페이지를 기록하여 진도 추적
    - 최근 기록을 상단에 노출
  - 기록이 쌓이면 날짜별 독서 히스토리 조회 가능
  - 기록 수정 및 삭제 가능
  - 읽고 싶음 상태에서 기록 추가 시 읽는 중으로 자동 전환
      - 다 읽음 상태에서는 읽는 중으로 변경 후 기록 가능
      - 기록 후 남은 페이지(전체 - 현재 기록)가 10% 또는 40쪽 이하이면 다이얼로그로 "혹시 책을 다 읽으셨나요?" 표시, "네" 선택 시 다 읽음 상태로 자동 전환
- 독서 상태 전환 규칙
    - 다 읽음으로 변경한 날짜 저장
    - 읽은 페이지와 무관하게 다 읽음으로 변경 가능(페이지 계산에는 실제 읽은 페이지만 반영)

### 3.4 내 서재

- 상태별 탭: 읽고 싶음 / 읽는 중 / 다 읽음
- 읽고 싶음 탭: 책 표지, 제목 표시
- 읽는 중 탭: 책 표지, 제목, 진행률 표시
- 다 읽음 탭: 다 읽은 날짜 표시
- 정렬: 추가한 날짜 / 수정한 날짜 / 별점순
    - 날짜는 최신순, 오래된순 선택 가능. 별점은 높은순, 낮은순 선택 가능
- 길게 눌러 메뉴 표시. 삭제, 상태 변경 메뉴 제공
    - 책 삭제 시 스낵바로 "책을 목록에서 삭제했어요", 취소 버튼 제공
    - 상태 변경 시 현재 상태 외 나머지 상태 표시 및 변경 가능, 스낵바로 "책 상태를 변경했어요" 취소 버튼 제공
- 텝/정렬 기본값: 읽는 중, 수정한 날짜-최신순

### 3.5 독서 통계

- **기간 전환**: 오늘 / 4주 / 1년 / 직접 선택으로 전환하여 요약 통계 조회
    - 기간, 독서 달력, 연속 기록, 읽은 페이지, 읽은 책, 그래프 표시
- 기간: 선택한 기간을 날짜 범위로 표시, 오늘은 오늘 날짜만 표시
- 독서 달력: 7일 그리드로 표시, 길면 가로 스크롤 가능. 읽은 페이지 수에 따라 색상 강도 표현 (0 / 1–19 / 20–49 / 50–99 / 100+ 페이지)
    - 날짜 클릭 시 해당 일 독서 기록 하단에 표시 - 표지, 제목, 해당 일 총 읽은 페이지 표시
- 연속 기록, 읽은 페이지, 읽은 책: 선택 기간 내 연속 기록 최댓값, 페이지, 책 합계 표시
- 그래프: 선택 기간 내 읽은 책, 페이지 그래프 표시, 책 막대 그래프, 페이지 꺾은 선 그래프, 가로 스크롤 가능.

### 3.6 설정

- 테마: 시스템 / 라이트 / 다크
- 알림: 독서 리마인더 (on/off, 알림 시간 설정)
  - 컨텍스트 기반 메시지: 가장 최근 '읽는 중' 책 제목을 포함, 없으면 일반 메시지로 fallback
- 지원: 오픈소스 라이선스, 버전 정보

## 5. 유저 플로우

```
[홈 탭]
  → 검색창 탭 → 검색 화면으로 이동
  → 바코드 스캔 버튼 탭 → 바코드 스캔 화면으로 이동
  → 읽는 중 책이 없을 때: 검색 또는 스캔 버튼 탭 -> 해당 화면 이동
  → 읽는 중 책 탭 → 책 상세로 이동
  → 읽는 중 섹션 "더보기" 버튼 탭 → 서재 탭으로 이동
  → 독서 요약 카드(독서 달력, 연속 기록 등) 탭 → 통계 탭으로 이동(필요하다면 위치로 스크롤)

[검색 화면]
  → 최근 검색어 탭 → 해당 검색어로 검색 실행
  → 검색어 입력 → 결과 목록에서 책 선택 → 책 상세로 이동
  → 검색 결과 없는 경우 → "바코드가 있나요? 바코드를 스캔해 보세요" → 바코드 스캔 화면으로 이동

[바코드 스캔 화면]
  → 카메라 권한 없음 → 권한 거부 화면 노출 ("카메라 사용" 버튼 탭 시 시스템 설정/프롬프트 이동)
  → ISBN 인식 성공 → 책 상세로 이동
  → ISBN 인식 실패 → "바코드를 인식하지 못했어요" 메시지 → 검색 화면 이동 버튼 탭 → 검색 화면으로 이동

[책 상세]
  → 독서 상태 설정 (읽고 싶음 / 읽는 중 / 완독) → 서재에 자동 추가
  → 독서 기록 추가
    → 읽고 싶음 상태: 기록 추가 시 읽는 중으로 자동 전환 후 저장
    → 읽는 중 상태: 기록 저장, 수정, 삭제 가능
      → 남은 페이지 10% 또는 40쪽 이하 → "혹시 책을 다 읽으셨나요?" 다이얼로그
        → "네" → 완독으로 전환, 완독일 저장
        → "아니요" → 기록만 저장
    →  완독 상태: 기록 추가, 수정, 삭제 불가
      → 읽는 중으로 상태 변경 → 읽는 중 상태로 기록 추가, 수정, 삭제 가능
  → 읽는 중 → 완독으로 상태 직접 변경 → 완독일 저장

[서재 탭]
  → 탭으로 상태 필터
  → 정렬 버튼 탭 → 정렬 기준(수정/추가/별점) 및 방향 필터(바텀 시트) 적용 → 목록 재정렬, 선택값 유지
  → 책 탭 → 책 상세로 이동
  → 삭제 및 상태 변경 메뉴 탭 → 즉시 처리 및 스낵바로 복구(Undo) 기능 제공
  → + 버튼 탭 → 검색 화면으로 이동

[통계 탭]
  → 독서 달력에서 날짜 칸 탭 → 달력 하단에 해당 날의 독서 기록 표시
  → 오늘 / 4주 / 1년 / 직접 선택(바텀 시트) 전환으로 요약 통계 조회

[설정 탭]
  → 테마 선택 (다크 / 라이트 / 시스템) → 즉시 적용
  → 독서 리마인더 알림 on/off 토글
    → on: 알림 시간 설정 → 매일 해당 시간에 알림 발송
    → off: 알림 비활성화
```

## 6. 데이터 소스

**국립중앙도서관 ISBN 서지정보 API** (data.go.kr 신청, 무료, 상업적 이용 가능)

활용 필드:
- 표제, 저자, 출판사, 발행일
- 표지 이미지 URL
- 책 소개, 목차
- 페이지 수, 가격, 분류 (한국십진분류)
- ISBN
