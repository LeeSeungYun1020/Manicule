# 읽음표

국어: 읽음표 - 나의 독서 기록
영어: Manicule — A Reader's Mark

## 1. 컨셉

읽은 책, 읽고 있는 책, 읽고 싶은 책을 한 곳에서 관리하는 개인 서재 앱.
국립중앙도서관 API로 국내 도서 서지 정보를 검색하고, 독서 상태와 메모를 기록한다.

---

## 2. 타겟 사용자

- 읽은 책을 기록해두고 싶은데 마땅한 앱이 없는 독서 애호가
- 독서 목표를 세우고 달성 여부를 확인하고 싶은 사람
- 서점에서 책을 발견했을 때 나중에 읽으려고 메모해두는 사람

---

## 3. 핵심 기능

### 3.1 홈

- 검색창 — 탭 시 검색 화면으로 이동 (키보드 자동 포커스)
- 바코드 스캔 버튼 — 탭 시 바코드 스캔 화면으로 이동
- 읽는 중인 책 목록 (섹션 헤더 우측 "더보기" 버튼 탭 시 서재 탭으로 이동)
- 독서 요약 카드: 독서 달력 미리보기 (최근 7일), 연속 기록 일수, 오늘 읽은 페이지 수 — 탭 시 통계 화면으로 이동
- 홈 상태별 표시
    - 첫 사용자(기록·서재 모두 없음): 통계·읽는 중 목록 대신 온보딩 안내를 표시. 빈 독서 요약 미리보기 + "이렇게 시작해 보세요" 시작 가이드(① 검색·스캔으로 책 추가 → ② 읽으며 기록 → ③ 통계로 습관 확인) + 검색·스캔 버튼
    - 기록/서재는 있으나 읽는 중인 책이 없을 때: 독서 요약 카드는 실제 기록이므로 계속 노출하고, '읽는 중' 목록 자리에 유도 카드 표시
        - 읽고 싶음 대기 도서가 있는 경우: "지금 읽는 책이 없어요" + 서재 '읽고 싶음' 탭으로 이동하는 '고르기' 버튼(+ 검색·스캔 아이콘 버튼)
        - 읽고 싶음 대기 도서가 없는 경우: "지금 읽는 책이 없어요" + 검색·스캔 버튼

### 3.2 책 검색

- 제목, 저자, ISBN으로 국내 도서 검색
- 검색 결과: 컴팩트 리스트 형태(표지 이미지, 제목, 저자, 출판사, 발행일)
- 최근 검색어: 검색어 히스토리 제공, 탭 시 해당 검색어로 재검색
    - 검색어 개별 삭제 가능 (삭제 즉시 실행되지 않고 스낵바 노출, '실행취소' 탭 시 복구)
    - 최근 검색어가 없는 경우(첫 사용 / 전체 삭제): "어떤 책을 찾고 있나요?" 제목과 "제목, 저자 또는 ISBN으로 검색해 보세요" 안내 표시
- 검색어 입력 중: 연관·추천 검색어 API를 제공하지 않으므로, 저장된 최근 검색어를 입력 변경마다 즉시 로컬 필터링하여 노출. 매칭 결과가 없으면 본문을 비우고, 입력을 지우면 최근 검색어 목록 또는 검색 유도 안내를 복원. 도서 검색은 키보드 검색(엔터) 또는 최근 검색어·필터 항목 탭으로 제출할 때 실행
    - 최근 검색어는 최대 10개만 보관한다.
- 검색 결과 없는 경우: "검색 결과가 없어요" 제목, "책에 있는 바코드를 스캔해 찾아보세요" 메시지. 스캔 버튼.
- ISBN 바코드 스캔으로 즉시 검색 (카메라 권한 필요)
    - 카메라 권한 거부 시 "카메라 접근 권한이 필요해요" 제목과 카메라 권한·직접 검색 안내를 표시한다. "카메라 사용" 버튼은 시스템 권한 프롬프트 또는 앱 설정으로, "검색" 버튼은 검색 화면으로 이동한다. 권한 요청·설정 열기에 실패하면 기기 설정 또는 검색을 안내한다.
    - 카메라를 사용할 수 없으면 카메라 상태 확인과 텍스트 검색을 안내한다.
    - 스캔 실패 시 "바코드를 인식하지 못했어요" 제목, "제목이나 저자로 검색해 찾아보세요" 메시지. 검색 버튼.

### 3.3 책 정보

- 책 정보, 내 기록 탭으로 구성
    - 진입 시 기본 탭: 내 서재에 없는 책은 '책 정보' 탭, 내 서재에 이미 있는 책은 '내 기록' 탭을 기본으로 표시
- 책 정보 - 표지, 정보(제목, 저자, 출판사, 발행일, 페이지, 가격), 소개, 목차
- 내 기록 - 독서 상태 설정, 내 리뷰, 독서 기록
- 상태: 읽고 싶음 / 읽는 중 / 다 읽음 설정
    - 미등록 또는 상태 미설정(`UNSET`) 책은 세 상태 모두 미선택으로 표시. 사용자가 상태를 탭하면 서재에 추가하며, 기존 리뷰가 있으면 보존
- 내 리뷰: 별점(1~5 정수) 및 메모 기록
    - 별도 다이얼로그나 바텀시트 없이 '내 기록' 탭 화면에서 바로 편집: 별을 탭하면 즉시 별점 저장(같은 별 재탭 시 0점), 메모 영역 탭 시 인라인 입력 후 포커스 아웃 시 자동 저장
    - 리뷰가 없는 경우: 점선 테두리와 빈 별(0점)로 작성 유도 UI 표시(동일 편집 컴포넌트의 빈 상태)
- 독서 기록: 읽은 날짜, 시작 쪽수, 끝 쪽수, 시간을 기록하여 진도 추적
    - 전체 페이지 대비 현재까지 읽은 페이지(끝 쪽수의 최댓값)를 프로그레스 바와 비율(%)로 상단에 표시
    - 최근 기록을 최상단에 노출하며 각 기록은 수정/삭제 가능
        - 기록 추가/수정: 바텀시트 제공. 날짜(오늘/어제/직접 선택), 시간(지금/직접 선택), 시작/끝 쪽수 입력. '직접 선택' 시 Android 표준 날짜 피커(Date picker)·시간 피커(Time picker) 사용
        - 기록 삭제: 즉시 삭제되지 않고 스낵바 노출, '실행취소' 탭 시 복구 (검색어 개별 삭제와 동일한 패턴)
    - 기록이 없는 경우: "아직 독서 기록이 없어요" 제목, "읽은 쪽수를 추가하면 매일 얼마나 읽었는지 확인할 수 있어요" 메시지.
  - 어느 상태(읽고 싶음 / 읽는 중 / 다 읽음)에서든 독서 기록을 추가·수정·삭제할 수 있다(다 읽은 책을 다시 읽는 경우 등 고려).
      - 미등록 책은 독서 기록 추가 시 서재에 '읽는 중'으로 등록하고, 상태 미설정(`UNSET`) 책은 기존 기록 유무와 관계없이 '읽는 중'으로 전환
      - 첫 기록이 생성되는 경우(기록이 없던 '읽고 싶음' 책) 읽는 중으로 자동 전환
      - 서재 등록·상태 전환과 기록 저장은 함께 성공하거나 함께 취소
      - 그 외 상태(읽는 중 / 다 읽음)에서는 기록 추가로 상태가 자동 전환되지 않고 현재 상태를 유지
      - 기록 후 남은 페이지(전체 - 현재까지 읽은 페이지)가 10% 또는 40쪽 이하이면 다이얼로그로 "혹시 책을 다 읽었나요?" 표시, "네" 선택 시 다 읽음 상태로 전환하고 다 읽은 날짜 저장, "아니요" 선택 시 기록만 저장
- 독서 상태 전환 규칙
    - 기록 추가에 따른 미등록·UNSET 책의 읽는 중 등록·전환과 첫 기록의 '읽고 싶음 → 읽는 중' 자동 전환을 제외하면, 상태 전환은 사용자가 명시적으로 수행
    - 다 읽음으로 변경한 날짜(다 읽은 날짜) 저장
    - 같은 상태를 다시 선택하면 수정 시각과 완독일을 유지. 다 읽음에서 다른 상태로 변경하면 완독일 제거
    - 읽은 페이지와 무관하게 다 읽음으로 변경 가능(페이지 계산에는 실제 읽은 페이지만 반영)

### 3.4 서재

- 상태별 탭: 읽고 싶음 / 읽는 중 / 다 읽음
- 읽고 싶음 탭: 책 표지, 제목 표시
- 읽는 중 탭: 책 표지, 제목 표시. 표지 하단에 진도율(%), 우측에 진도율 나타내는 책갈피 모양 오버레이 표시
- 다 읽음 탭: 책 표지, 제목 표시. 표지 하단에 다 읽은 날짜(YYYY/M/D) 오버레이 표시
- 책이 없는 경우(모든 탭 공통): "서재가 비어 있어요" 제목, "책을 검색하거나 스캔해 서재에 담아 보세요" 메시지. "검색", "스캔" 버튼.
- 정렬: 추가한 날짜 / 수정한 날짜 / 별점
    - 정렬 바텀시트를 통해 기준 선택 → 하단에 펼쳐지는 방향 세그먼트(날짜: 최신순/오래된순, 별점: 높은순/낮은순) 선택 → '적용' 버튼으로 확정
    - 앱바에는 정렬 아이콘만 배치하고, 현재 선택된 정렬 상태(예: `수정한 날짜 · 최신순`)는 **상태 탭 아래·목록 위**에 텍스트로 표기
    - 별점순 정렬 시, 별점이 동일한 항목들은 '수정한 날짜' 최신순으로 2차 정렬됨. 별점이 없는 항목은 0점으로 취급.
- 길게 눌러 메뉴 표시. 삭제, 상태 변경 메뉴 제공
    - 책 삭제 시 스낵바로 "책을 목록에서 삭제했어요", 취소 버튼 제공
    - 상태 변경 시 현재 상태 외 나머지 상태 표시 및 변경 가능, 스낵바로 "책 상태를 변경했어요" 취소 버튼 제공
- 탭/정렬 기본값: 읽는 중 탭, 수정한 날짜 - 최신순. 이후 사용자가 선택한 값을 유지한다.
- 책 추가 버튼은 검색 화면으로 이동한다.

### 3.5 독서 통계

- **기간 전환**: 오늘 / 4주 / 1년 / 직접 선택으로 전환하여 요약 통계 조회
    - 기간, 독서 달력, 연속 기록, 읽은 페이지, 읽은 책을 표시하고 오늘에는 책 목록, 다른 기간에는 그래프를 표시
    - 오늘 탭: 그래프 대신 오늘 읽은 책 목록(표지, 제목, 읽은 횟수, 읽은 쪽수)을 표시. 항목 탭 시 해당 책의 기록 탭(5b)으로 이동
    - 직접 선택 탭: 시작일과 종료일을 설정하는 '기간 설정' 바텀 시트 제공. 시작일은 종료일 이전 또는 같은 날이어야 하며, 미래 날짜와 365일 초과 범위는 허용하지 않는다. '적용' 확정 시 커스텀 날짜 범위의 통계 표시
- 기간: 선택한 기간을 날짜 범위로 표시, 오늘은 오늘 날짜만 표시
- 시간축: 독서 달력과 그래프는 읽기 방향에 따라 과거→최신 순으로 배치한다(LTR: 왼쪽→오른쪽, RTL: 오른쪽→왼쪽). 길면 가로 스크롤하며, 진입 시 최신 항목이 보이도록 한다.
- 독서 달력: 4주·1년·직접 선택에서는 Y축을 요일(월~일), X축을 주(Week) 단위로 구성하고, 오늘에서는 최근 7일을 한 줄로 표시한다. 읽은 페이지 수에 따라 색상 강도를 5단계(0 / 1–19 / 20–49 / 50–99 / 100+ 페이지)로 표현
    - 주 시작 요일은 현재 월요일로 고정한다. 월요일/일요일 선택 설정은 [#46](https://github.com/LeeSeungYun1020/Manicule/issues/46)에서 별도로 구현한다.
    - 날짜 선택 여부와 무관하게 밀집형 셀 크기와 간격을 유지한다. 달력 셀은 최소 48dp 터치 크기의 예외로, 기록이 있는 셀 자체를 한 번 탭하면 해당 일 독서 기록 바텀 시트를 표시한다(표지, 제목, 해당 일 총 읽은 페이지). 단, 오늘 탭의 오늘 셀은 바텀 시트 대신 화면 아래의 '오늘 읽은 책' 목록으로 스크롤한다. 간격·패딩·기록 없는 날짜는 반응하지 않으며, 별도 선택 UI는 제공하지 않는다.
- 연속 기록, 읽은 페이지, 읽은 책: 선택 기간 내 최장 연속 기록, 누적 페이지 수, 독서 기록에 나타난 고유 ISBN 수를 표시한다. 읽은 책은 완독 권수가 아니다.
- 그래프: 책은 막대 그래프, 페이지는 꺾은선 그래프가 겹쳐진 복합 차트(Combined Chart)로 표시.
    - 좌측 Y축은 책 권수, 우측 Y축은 페이지 눈금을 표시하고 배경에 점선 격자선을 둔다. 가로 스크롤되는 기간(1년 등)에서는 좌우 축을 고정하고 가운데 그래프 영역만 스크롤
    - 오늘을 제외한 기간에는 일·주·월 집계 단위를 모두 선택할 수 있다. 4주는 주, 1년은 월을 기본으로 하고 직접 선택은 1~14일은 일, 15~90일은 주, 91일 이상은 월을 기본으로 한다. 사용자가 고른 단위는 기간 탭마다 유지하며 직접 선택 범위를 다시 적용해도 유지한다.
    - 일은 날짜별, 주는 월요일~일요일, 월은 월초~월말로 묶고 선택 범위 밖 날짜는 제외한다. 구간별 책 권수는 독서 기록에 나타난 고유 ISBN 수, 페이지는 기록의 읽은 쪽수 합이다. 기록 없는 구간도 0으로 표시하며, 구간별 권수 합은 기간 요약 권수와 다를 수 있다.

### 3.6 설정

- 화면:
    - 테마: 시스템 / 라이트 / 다크 (세그먼트 컨트롤). 선택 즉시 적용한다.
- 알림:
    - 독서 리마인더: 토글 스위치로 on/off. 리마인더가 on일 때만 하단에 '리마인더 시간' 행 노출 (탭 시 시간 피커(Time picker) 표시). 설정한 시각에 매일 발송한다.
    - Android 13 이상에서 알림 권한이 없으면 리마인더를 켤 때 권한을 요청한다. 권한 설명이 필요한 경우 안내 다이얼로그를 먼저 보여 주고, 거부 시 스낵바에서 앱 알림 설정으로 이동할 수 있다. 권한을 얻기 전에는 리마인더를 켜지 않는다.
- 컨텍스트 기반 메시지: 최근 업데이트된 일부 '읽는 중' 책을 후보로 삼아 제목을 최대 2권 포함한다. 후보가 3권 이상이면 무작위로 2권을 선택하며, 후보가 없으면 일반 메시지로 fallback한다.
- 지원:
    - 오픈소스 라이선스 화면 진입, 현재 앱 버전 정보 표기

## 5. 화면 간 이동

화면 안의 탭·시트·다이얼로그와 편집·실패 처리는 위 핵심 기능에 둔다. 검색 결과는 같은 검색 화면의 상태지만 별도 프로토타입이므로 진입을 표시한다.

| 출발 | 동작 | 도착 |
|---|---|---|
| 하단 탭 | 다른 탭 선택 | 홈·서재·통계·설정 |
| 홈 | 검색창·빈 상태 검색 버튼 선택 | 검색 |
| 홈 | 스캔·빈 상태 스캔 버튼 선택 | 스캔 |
| 홈 | 읽는 중 책 선택 | 책 상세 |
| 홈 | '더보기' 선택 | 서재의 읽는 중 탭 |
| 홈 | '고르기' 선택 | 서재의 읽고 싶음 탭 |
| 홈 | 독서 요약 카드 선택 | 통계 |
| 검색 | 검색어 제출·최근/필터 항목 선택 | 검색 결과 상태 |
| 검색 결과 | 책 선택 | 책 상세 |
| 검색 결과 없음 | 스캔 버튼 선택 | 스캔 |
| 스캔 | 도서 조회 성공 | 책 상세 |
| 스캔 | 실패 또는 권한 거부 화면에서 검색 선택 | 검색 |
| 스캔 권한 거부 | '카메라 사용' 선택 | 시스템 권한 요청 또는 앱 설정 |
| 서재 | 책 선택 | 책 상세 |
| 서재 | 책 추가·빈 상태 검색 버튼 선택 | 검색 |
| 서재 빈 상태 | 스캔 버튼 선택 | 스캔 |
| 통계 오늘 목록 | 책 선택 | 해당 책의 내 기록 탭 |
| 설정 | 오픈소스 라이선스 선택 | 라이선스 화면 |
| 하위 화면 | 앱바·시스템 뒤로가기 | 이전 화면 |
